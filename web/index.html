Restore default Plex posters

Switches every top-level item (movies and shows) in a library back to its clean Plex agent poster — the provider poster, with no overlays baked in. The clean poster is put back as a fresh upload of the agent's own poster image (image-identical): merely re-selecting the agent poster does not update what Plex clients display, while a fresh upload does. Nothing is deleted: the current poster is backed up first (verified, in History), and the old uploaded image stays in Plex, just deselected. This card covers top-level items only; to put an item back on its own saved original — at any level — use Restore backed-up posters below.

Starting…

Restore backed-up posters

Puts items back on the original poster saved before an overlay was applied — at any level: movies, shows, seasons, and episodes. Only items with a saved backup appear here; an item with no backup is never listed, and no provider poster is ever offered as a substitute original. Restores are recorded in History with their level.

Leaving soon

Your own list of titles leaving this server, with the dates you set — the dates live in this app, not in Plex, and nothing reads them from anywhere else. The Leaving soon badge family (in the Studio) draws its banner from this list when overlays are applied: a badged poster shows the list as of apply time, so changing a date afterwards does not redraw posters already badged — re-apply to update them. Entries whose date has passed stay listed as expired until you remove them.

Pinned badges

Free-text badges you pin to titles directly — they draw on that title's poster whatever the layout or template, and they are NOT part of any template. Pin from the Studio's “Pin a badge to this title” button, or pin one badge to a whole collection below. A collection pin expands into one pin per current member: titles added to the collection later do not get the pin — pin again to cover them.

Configuration

Settings

Appearance, API keys and Advisor tuning. Keys are stored in Windows Credential Manager (or the encrypted fallback) — the UI never sees a value, only whether one is set.

Appearance

Themes recolor the whole app — shell, panels, text, accents — and apply the moment you pick one. Your choice is saved in the app's settings, so it survives restarts. The Custom editor starts from whichever theme is active; edits apply live, and picking a color makes that surface solid.

Cache & history

Cache: —

Clearing the cache re-fetches TMDb/Trakt/OMDb data on the next scan (rate limits apply). Dismissals and drafts are never cleared by this.

Backup & restore

Export downloads one JSON file with your portable settings: appearance and custom theme, Advisor tuning, overlay templates, and Leaving Soon dates. It never includes your server choice, your sign-in, or cached art — those belong to this machine.

Only check this if you need your keys on the new machine. Anyone who opens that file can read them — keep it private, and delete it after the move.

Import replaces your portable settings with the file's, adds or overwrites overlay templates by name, and replaces the Leaving Soon list. Your server choice and sign-in are never touched, even if the file mentions them.

Donate button

Shows a floating Ko-fi donate button (the Ko-fi overlay widget) in the corner of the app whenever the toggle is on, a username is set, and the widget script loads. Toggle off and no script loads at all; no username, or no internet, means no button — nothing breaks, nothing complains. The username is yours to change — a forker points it at their own Ko-fi.
